# ARCodes

ARCodes is a responsive, browser-based developer toolkit built as a lightweight static website.

## Included tools
- HTML formatter
- JSON validator, pretty-printer, and minifier
- Base64 encoder/decoder with UTF-8 support
- URL component encoder/decoder
- JavaScript regular-expression tester
- UUID v4 generator
- Unix timestamp/date converter
- HEX/RGB color converter and preview

## Run locally
Open `index.html` in a browser. No build step, dependencies, backend, or environment variables are required.

## Deploy
Import this repository into Vercel or any static hosting provider. The site uses `index.html` as its entry point.

## Privacy
Tool processing happens in the browser. The site does not send entered snippets to an API.
